💡 Solusi Jika Muncul "Aplikasi Tidak Dapat Diinstal" di Android:
  1. Penyebab Sebelumnya: Chrome Android menolak instalasi jika halaman belum memiliki generator ikon PNG 192x192 & 512x512. Pada versi terbaru ini, mesin PNG Icon Generator Spider Team sudah ditanamkan secara otomatis.
  2. Cara Pasang Paling Pasti di Chrome Android:
    • Buka link GitHub Pages Anda di Chrome, lalu Refresh (Muat Ulang) 1 kali agar kode baru terbaca.
    • Ketuk Titik Tiga (⋮) di kanan atas Chrome → pilih "Tambahkan ke layar utama".
    • Jika muncul 2 pilihan ("Instal aplikasi" vs "Buat pintasan / Tambahkan ke layar utama"), pilihlah atau coba keduanya—keduanya langsung memunculkan ikon AFC Spider Team di layar HP Anda!
  3. Tips GitHub (Opsional): Anda juga bisa mengunggah file logo spider.jpg ke folder repository GitHub yang sama dengan index.html agar otomatis terbaca di semua perangkat.
